# Suraj K. Gaikwad — Academic Website

A minimalist academic portfolio website inspired by modern scientist/researcher personal sites.

## Files

- `index.html` — website content
- `style.css` — design and responsive layout
- `script.js` — theme toggle and year
- `CV.pdf` — add your CV here
- `assets/` — add your profile photograph and other images here

## Before publishing

Search the files for:
- `YOUR_EMAIL@example.com`
- placeholder publication titles
- placeholder social links
- `Your photograph`

Replace them with your real information.

## GitHub Pages

1. Create a GitHub repository, e.g. `surajgaikwad.github.io`.
2. Upload all files from this folder.
3. In GitHub: Settings → Pages.
4. Select the main branch and root folder.
5. Save.
6. Your website will be available at your GitHub Pages address.
